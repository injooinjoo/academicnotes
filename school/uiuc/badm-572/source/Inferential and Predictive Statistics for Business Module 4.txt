Multiple Regression Model (2 of 2) - Slide 2
One response (dependent) variable
Multiple explanatory (independent) variables
Transcript
The main difference in multiple regression as compared to simple linear regression is the ability to
have more than one explanatory variable in our analysis. We still have one response variable, y, but
now, we can have many explanatory variables, which are our x's.
There is no limit to the number of independent variables a model can use, which means multiple
regression models can handle more complex situations than the simple linear regression models.

A study done on newborns established a predictive equation for childhood and adolescent obesity.

Transcript
There was one element of Excel output in the top table that I never reviewed when we were learning
about simple linear regression, and that is adjusted R-squared. We have learned that R-squared is
the proportion of the total variations that is explained by the overall regression model. When we have
multiple regression, the valuable R-squared will increase even if the new variables being added to the
model has no relationship to y. Adjusted R-squared corrects this tendency in R-squared.
As you can see here, adjusted square is smaller than R-squared and this will always be the case.
While we used R-squared in simple linear regression to know what percent of variations were
explained by the regression model, in multiple regression, it will be use the adjusted R-squared to
find the proportion.
Testing the Significance - Slide 7
Adjusted R2 shows the proportion of the total variation that is explained by the overall regression
model.
For every independent variable test: Null: There is no relationship between the independent variable
and the response variable.
If p-value < significance level, then there is a significant relationship between the regression
variable and y.

14
Transcript
While adjusted R-squared value will tell us how good the regression model is in explaining the
variations, the significance of each independent variable is assessed separately. In multiple
regression, it is customary to test the significance of every independent variable used in the model.
Again, the null hypothesis for each independent variable state that no relationship exists between the
independent variable and the response variable. Therefore, if p-value is less than significance level,
then we would be rejected the null hypothesis, meaning that there is a significant relationship
between the regression variable and the response variable.
